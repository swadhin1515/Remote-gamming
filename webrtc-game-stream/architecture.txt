│ How to Play                                                                                                                                                                               │
│                                                                                                                                                                                           │
│ 1. Access the Game                                                                                                                                                                        │
│ Open your web browser and navigate to:                                                                                                                                                    │
│  1 http://localhost:8080                                                                                                                                                                  │
│                                                                                                                                                                                           │
│ 2. Wait for Connection                                                                                                                                                                    │
│  - The page will automatically connect to the signaling server                                                                                                                            │
│  - Wait for the status to show: "✅ Receiving video stream"                                                                                                                               │
│  - You should see the snake game displayed in the video player                                                                                                                            │
│                                                                                                                                                                                           │
│ 3. Start Playing                                                                                                                                                                          │
│  - Click on the video area to focus it for input                                                                                                                                          │
│  - Use these controls to play:                                                                                                                                                            │
│    - Arrow Keys or WASD: Move the snake                                                                                                                                                   │
│    - P: Pause/Unpause                                                                                                                                                                     │
│    - Q: Quit game                                                                                                                                                                         │
│                                                                                                                                                                                           │
│ 4. Game Objective                                                                                                                                                                         │
│  - Control the snake to eat food (@)                                                                                                                                                      │
│  - Avoid hitting walls or yourself                                                                                                                                                        │
│  - Your score increases with each food eaten                                                                                                                                              │

│ Troubleshooting                                                                                                                                                                           │
│                                                                                                                                                                                           │
│ If you don't see video:                                                                                                                                                                   │
│  1 # Check container logs                                                                                                                                                                 │
│  2 cd /root/webrtc-game-stream                                                                                                                                                            │
│  3 docker compose logs game                                                                                                                                                               │
│  4                                                                                                                                                                                        │
│  5 # Restart if needed                                                                                                                                                                    │
│  6 docker compose restart game                                                                                                                                                            │
│                                                                                                                                                                                           │
│ If input doesn't work:                                                                                                                                                                    │
│  - Make sure you clicked on the video area to focus it                                                                                                                                    │
│  - Check browser console (F12) for any errors                                                                                                                                             │
│                                                                                                                                                                                           │
│ System Architecture                                                                                                                                                                       │
│                                                                                                                                                                                           │
│ The system consists of three Docker containers working together:                                                                                                                          │
│  - Signaling Container: WebSocket server for WebRTC negotiation                                                                                                                           │
│  - Game Container: Runs snake game in Xvfb, captures screen, streams via WebRTC, handles input                                                                                            │
│  - Web Container: Serves the HTML/JS client interface                                                                                                                                     │
│                                                                                                                                                                                           │
│ Enjoy playing Snake via WebRTC streaming!

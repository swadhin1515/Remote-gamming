📋 How It Works

  • 🔄 Auto-Scaling: Opening a tab increases deployment replicas by 1
  • 🎯 Kubernetes Native: Uses Deployment scaling, not individual pods
  • 🎮 Replica Assignment: Each tab gets assigned to a specific replica
  • 🧹 Scale Down: Closing tabs automatically reduces replicas
  • 📊 Resource Efficient: Only runs pods when needed

🎯 Controls

  • Click video: Lock mouse pointer for game control
  • ESC key: Release mouse pointer
  • Arrow keys / WASD: Game controls (depends on game)

⚙️ Architecture

  • Session Scaler: Monitors connections and scales deployment
  • Game Deployment: Starts at 0 replicas, scales dynamically
  • Room Assignment: Each replica gets unique room (e.g., room-test-1, room-test-2)
